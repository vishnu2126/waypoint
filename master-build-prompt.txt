# MASTER BUILD PROMPT

## Developer Navigation Engine — V1

You are the lead product engineer, UX engineer, software architect, and UI designer for this project.

Your task is to BUILD the complete web application described below.

Do not merely explain how to build it.
Do not give me isolated code snippets.
Inspect the existing repository first, understand its current structure, and then implement the application directly in the repository.

If something is missing, create it.

The goal is to create a highly polished, production-quality Developer Navigation Engine that feels fundamentally different from traditional developer roadmap websites.

---

# 1. PRODUCT VISION

Build a web application that acts as a:

> "Developer GPS"

The application should help a user determine:

1. Where they currently are in their developer journey.
2. Where they want to go.
3. What skills they already have.
4. Which skills they are missing.
5. Which skills are prerequisites for others.
6. Which skill they should learn next.
7. Which technologies they should NOT learn yet.
8. Which alternative paths exist.
9. How close they are to becoming job-ready for a chosen role.

This is NOT simply a collection of static roadmaps.

The core product is a personalized, interactive skill-navigation system.

The main product principle is:

> "You don't need to know the whole road. You need to know the best next turn."
